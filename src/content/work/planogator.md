## Overview

Planogator is a browser planogram builder MVP. Import products from CSV, arrange bays and shelves, adjust facings, and save or patch planograms through a small Node API backed by SQLite.

## Highlights

- Canvas editing with zoom, drag and drop, undo/redo, and keyboard shortcuts
- CSV import with column mapping and catalog conflict checks
- Capacity, sales, revenue, and shelf-usage views
- Aisle builder for top-down store layout
- Realistic 3D-style shelf view

## Status

Local-first tooling for planogram design. See the `retail` repository's `apps/planogator` folder for setup and run commands.
